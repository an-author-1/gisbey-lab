# data/

Corpus manifest, versioned sentence mappings (e.g. F12.S1–F12.S9), and derived data.

`corpus_manifest.json` (paths, hashes, order — written by `gibsey validate-corpus`),
`sentence_map.F12.json` (proposed/reviewed sentence mapping), and, once a run is proposed/
accepted/preserved, `proposals.json`, `bonds.json`, `reader_state.json`, and `gibsey_vault/`
(the reader's Gibsey Vault — distinct from the Obsidian source `vault/`). See the root
`README.md`, "Implementation Status and Commands."
